# Memory Engine

## Overview

The Memory Engine manages all information within Aadhini OS.

It is responsible for storing, retrieving, updating and organizing knowledge while preserving context and history.

## Memory Types

### Temporary Memory

Stores active conversations, current tasks and session data.

### Permanent Memory

Stores owner preferences, verified knowledge and long-term information.

### Archive Memory

Stores historical records and completed activities for future reference.

## Responsibilities

- Store information
- Retrieve information
- Maintain context
- Preserve history
- Support reasoning
- Enable learning

## Connected Modules

- Decision Engine
- Knowledge Engine
- Task Manager
- Workflow Engine

## Engineering Rules

- Every new information starts in Temporary Memory.
- Promote information only after validation.
- Never lose context.
- Preserve historical records.
- Support explainable retrieval.
