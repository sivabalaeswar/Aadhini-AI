# Rule Engine

## Overview

The Rule Engine validates every action before execution.

Rules are independent of business logic and ensure safety, security, privacy and compliance.

## Responsibilities

- Validate requests
- Apply owner policies
- Apply security policies
- Check permissions
- Verify constraints
- Prevent invalid execution

## Rule Categories

- Security Rules
- Privacy Rules
- Owner Rules
- Device Rules
- Workflow Rules
- AI Safety Rules

## Connected Modules

- Decision Engine
- Guardian Engine
- Memory Engine
- Task Manager

## Engineering Rules

- Rules execute before Task Manager.
- Rules cannot be bypassed.
- Rules are version controlled.
- Every rejection must include a reason.
