# Aadhini AI Agents

## Master Core
Maintains system identity and coordinates all major modules.

## Decision Agent
Evaluates user intent and determines the execution path.

## Memory Agent
Manages temporary, permanent and archival memory.

## Rule Agent
Applies system policies, constraints and validations before execution.

## Guardian Agent
Protects the user, data and connected devices.

## Task Agent
Schedules and monitors task execution.

## Knowledge Agent
Maintains the knowledge base and retrieves contextual information.

## Planning Agent
Breaks complex goals into executable tasks.

## Workflow Agent
Automates repetitive business and personal workflows.

## Notification Agent
Manages notifications and user communication.

## Engineering Rule

Every agent has a single responsibility.

Agents communicate only through approved interfaces.

No agent bypasses the Decision Engine.
